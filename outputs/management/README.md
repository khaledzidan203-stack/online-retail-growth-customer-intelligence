# Management Excel outputs

These workbooks are generated by [management_export.py](../../src/exports/management_export.py) from [read-only SQL queries](../../src/exports/sql_queries.py) against the governed analytics layer.

| File | Contents |
|---|---|
| [Online_Retail_Management_Analytics.xlsx](Online_Retail_Management_Analytics.xlsx) | 14 sheets: executive summary, monthly sales, markets, products, customers, RFM, retention, cancellations, adjustments, data quality and dictionaries |
| [Online_Retail_Analytical_Detail.xlsx](Online_Retail_Analytical_Detail.xlsx) | 16 sheets: Customer360, RFM, cohort, repeat behavior, cohort revenue/retention, product/market detail and exceptions |
| [management_export_validation.json](management_export_validation.json) | PASS for SQL validation and reference reconciliation; 82,847 management cells and 433,816 detail cells validated |

From the repository root, after completing SQL/customer analytics setup:

~~~powershell
python src/exports/management_export.py --server localhost --driver "ODBC Driver 18 for SQL Server"
python src/exports/management_export.py --server localhost --driver "ODBC Driver 18 for SQL Server" --validate-only
~~~

Generation writes formatted workbooks; validation compares saved analytical cells with fresh SQL results. It creates no SQL objects and uses Windows authentication.

Monetary values use source-currency units. Distinct counts and rates are nonadditive. Management product/cancellation lists are explicitly Top N; 2009 and 2011 are partial periods. Publication preserves the original workbook bytes and analytical values.
